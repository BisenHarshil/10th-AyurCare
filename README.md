# AyurCare 🌿

###"AyurCare isn't just running on my laptop — it's live on the internet. Anyone can open it right now."

### Ancient wisdom for modern health

AyurCare is a web application built for anyone who wants to explore Ayurveda — 
check symptoms, discover herbs, track daily health habits, and get Ayurvedic 
remedies in seconds. No doctor visit needed for everyday wellness.

---

## Why I Built This

Ayurveda is one of the oldest and most powerful medical systems in the world — 
and it is deeply rooted in Indian culture. Yet most people today don't know which 
herb helps with stress, or what to do when a family member has fever.

I built AyurCare to bring that ancient knowledge into a simple, modern web app 
that anyone can use from their phone or laptop. This was also a topic nobody else 
was building — and I wanted my project to stand out.

Built in 1 weeks by a Class 10 student. From scratch. No templates. No shortcuts.

---

## Features

- 🌡️ **Symptom Checker** — Select one or more symptoms and get Ayurvedic remedies,
  recommended herbs and lifestyle advice instantly
- 🌱 **Herb Database** — Browse 8 powerful Ayurvedic herbs with benefits,
  description and how to use them
- 🔍 **Herb Search** — Search any herb by name or by what it treats
- 🧘 **Habit Tracker** — Log daily water, sleep and diet to get a personalised
  Ayurvedic health score with improvement tips
- 💡 **Daily Tips** — A new Ayurvedic tip every time you visit the home page
- 📖 **About Page** — The story behind the project

## How to Run

**Step 1 — Clone the repository**
```bash
git clone https://github.com/BisenHarshil/AyurCare.git
cd AyurCare
```

**Step 2 — Install Flask**
```bash
pip install flask
```

**Step 3 — Run the app**
```bash
python app.py
```

**Step 4 — Open in browser**
```bash
http://127.0.0.1:5000
```
###🔗 Live Demo: https://one0th-ayurcare.onrender.com
